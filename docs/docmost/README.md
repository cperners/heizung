# Import in Docmost

Im gewünschten Bereich neben „Pages“ das Menü „…“ öffnen, „Import pages“ wählen und
unter „Markdown“ die Datei **ESP32-Heizung-Docmost.md** importieren. Das ergibt eine
zusammenhängende Seite mit allen zwoelf Kapiteln.

Alternativ unter „Import zip file“ das Paket **ESP32-Heizung-Docmost-Kapitel.zip**
importieren. Es enthält dieselben Inhalte als zwoelf einzelne Markdown-Seiten.
Nicht beide Varianten in denselben Bereich importieren, wenn keine Duplikate gewünscht sind.

Die Unterstützung hängt von der installierten Docmost-Version ab. Verweise zwischen
Kapiteln führen zum GitHub-Wiki und sind keine automatisch erzeugten Docmost-Seitenlinks.

Offizielle Import-Anleitung: https://docmost.com/docs/user-guide/import-export

Die Dateien enthalten Projekt- und Hardwareinformationen, jedoch keine produktiven
Passwörter und keine Firmware-BIN. Noch offene Gerätetests sind in den Kapiteln markiert.

Nur die neuesten Ergaenzungen importieren: **Heizkurve-und-MQTT-Schaltereignisse.md**.
Diese Datei enthaelt auch die vollstaendige Node-RED-Funktion.
